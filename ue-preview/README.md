# ANLB UE 關鍵幀演示

獨立靜態演示：十面既有內容搭配 13 張 2026-09-07 UE 實機截圖。無後端，不會連接或控制展場設備。

- 四章切換、上／下一段、段落直選、播放／暫停、待機、放大。
- 待機保留完整導播牆排列，各螢幕切換品牌待機內容，平板顯示可點按的待機入口；開始從序章播放，也可直接選章。暫停才是停住原畫面。
- 初始停在序章第一張，方便講解；播放後四章共 180 秒自動循環。
- UE 主畫面為各段關鍵幀，不是即時畫面，也不模擬段內 UE 動畫。
- 所有 13 張均依使用者決定使用，包含地下揭示與核心的現況截圖。
- 內嵌平板與同瀏覽器另開的平板頁共用操作狀態；不同裝置或不同瀏覽器不互相遙控。
- `ue-frames.json` 記錄圖片與段落對應；不包含維運端點、SSH 資料或控制記錄。
- 靜態資產使用相對路徑，支援 GitHub Pages 的子目錄。

Three.js 遵循 `vendor/package/LICENSE`。品牌、原模型、UE 截圖與文案沿用本專案授權素材。
