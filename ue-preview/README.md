# ANLB UE 關鍵幀演示

獨立靜態演示：十面既有內容搭配 2026-09-07 UE 正常展演逐秒截圖序列。無後端，不會連接或控制展場設備。

- 四章切換、上／下一段、段落直選、播放／暫停、待機、放大。
- 待機保留完整導播牆排列，各螢幕恢復原版黑底、小 Logo、小字主視覺待機內容，平板獨立顯示原本的大 Logo 待機入口；開始從序章播放，也可直接選章。暫停才是停住原畫面。
- 初始停在序章第一張，方便講解；按下播放後每 2 秒切換一段，13 段共 26 秒自動循環；各段動畫與 UE 圖片序列按實際展演時間等比例加速。
- UE 主畫面使用正常展演每秒一張的實機截圖。按主控實際設定，序章／生命履歷／數位孿生每段 12 秒、BOS 每段 18 秒，因此演示段內分別每 1/6 秒、1/9 秒更新來源圖片。瀏覽器顯示節奏受裝置效能影響。
- 播放前預載圖片；暫停停住當前圖片，放大同樣跟隨段內序列。
- 保留原 13 張代表圖作初始與固定分鏡預覽；新序列使用此次 UE 實機採集，BOS 地下核心仍是現場版本的效果。
- 內嵌平板與同瀏覽器另開的平板頁共用操作狀態；不同裝置或不同瀏覽器不互相遙控。
- `ue-sequence.json` 記錄逐秒圖片、來源秒數與段落對應；`ue-frames.json` 保留原代表圖清單；不包含維運端點、SSH 資料或控制記錄。
- 靜態資產使用相對路徑，支援 GitHub Pages 的子目錄。

Three.js 遵循 `vendor/package/LICENSE`。品牌、原模型、UE 截圖與文案沿用本專案授權素材。
